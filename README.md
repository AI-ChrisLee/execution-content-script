# execution-content-script

This agent is a base. Once you have done it your way, tell your squad "update the agent to do it like this."

It writes your YouTube script, `03_SCRIPT.md`, in your episode folder. First it writes the prep, `00_PREP.md`: the winning video outlined, and what every tool costs, read off each tool's own page. You read the prep. Then it writes the script.

**Install.** Installed with the one line on aichrislee.com/free, then quit and reopen Claude Code.

**What it reads.** The package execution-content-scrape locked in `squad/week/`, and the winner file that package names. Your offer page, `squad/business.md`, says who the video is for. The real messages you gave your squad on day 1 are the voice.

**Run it.** Type "Write the money script." It asks 2 things: 1 real moment when something went wrong, broke or surprised you, and what on your screen shows the thing you sell working. Read the prep, fix a word, then type "The prep is approved." The script lands in the same folder.

It never records, posts or publishes. The recording is yours.
